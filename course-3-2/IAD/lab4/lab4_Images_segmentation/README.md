# Лабораторная работа №4: Сегментация изображений

## 📋 Описание
Семантическая сегментация облаков на спутниковых снимках с использованием U-Net архитектуры.

## 🎯 Задача
- Присвоение метки класса каждому пикселю изображения
- 5 классов: фон + 4 типа облаков (Fish, Flower, Gravel, Sugar)

## 📊 Датасет
- **Название:** Cloud Organization (Kaggle)
- **Объём:** 5 546 изображений
- **Размер:** 128×128 пикселей
- **Классы:** 5 (0=фон, 1-4=типы облаков)

## 🏗️ Архитектура
- **Задание 1:** U-Net с нуля (encoder-decoder со skip-connections)
- **Задание 2:** U-Net с pretrained encoder (ResNet18)

## 📈 Метрики
- Mean IoU (Intersection over Union)
- Dice Score
