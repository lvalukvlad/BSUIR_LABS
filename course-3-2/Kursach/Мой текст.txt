Общая рамка команды (1–1,5 мин)
Добрый день. Мы представляем курсовой проект по веб-интерфейсу метасистемы OSTIS: клиент на React / TypeScript, связка с sc-web, sc-machine и базой знаний. Цель — сделать работу пользователя с системой понятнее: навигация, поиск, диалоговая помощь и подсказки.

Дальше по моей зоне — Лукашов Владислав.

Моя зона ответственности — обзор (30–40 сек)
Я отвечал за интеллектуальную поддержку в интерфейсе в первую очередь через модуль AskAI и контекстные подсказки: чтобы пользователь мог задать вопрос естественным языком, получить ответ из базы знаний, а в ключевых местах — подсказки без обращения к документации.

AskAI: что видит пользователь (1 мин)
На экране AskAI три элемента:

Приглашение и поле ввода.
Кнопки-примеры — типовые вопросы в текущем языке интерфейса.
После отправки — экран диалога: история «вопрос — ответ» и поле для уточняющих вопросов.
Навигация: отдельная ветка маршрута /ask-ai/, вложенный экран ответа. История диалога хранится в Redux (requestDialogHistorySlice). При уходе из раздела AskAI история сбрасывается (в актуальной ветке react-sc-web — при размонтировании AskMain), чтобы не смешивать сессии.

AskAI: как устроено в коде (2–2,5 мин)
AskPage только собирает вопрос и делает navigate на экран ответа с state: текст и флаг «это с кнопки-подсказки».

AskAnswer вызывает getDescriptionById(query, lang) и кладёт результат в историю. Пустой ввод и ошибки обрабатываются понятными сообщениями, без «технического» текста.

Ключевой модуль — getDescription.ts:

Нормализация запроса (регистр, пунктуация, типичные опечатки по-русски).
Словарь алиасов — разные формулировки одного смысла (например IMS/ИМС, варианты sc-памяти).
Тип запроса — в первом приближении: определение, действие, навигация или другое; от этого зависит порядок шагов.
Дальше — два канала к знаниям (это важно для понимания архитектуры):

HTTP POST /api/kb/search/ — запрос уходит на sc-web; там уже выполняется поиск по загруженной базе. Фронт получает JSON с полем answer и при необходимости флагом низкого качества.
Прямая работа с SC-памятью по WebSocket (ts-sc-client): по тексту ищутся sc-ссылки, узел — по nrel_main_idtf / nrel_system_identifier, затем может вызываться команда ui_menu_summary — краткая сводка по элементу.
Ответы не подставляются «с потолка» из клиента: либо из БЗ / агентов, либо явное сообщение «определение не найдено». В учебной ветке ostis-metasystem кнопки-подсказки могут использовать локальные заготовки; в react-sc-web те же кнопки завязаны на getDescriptionById и реальную БЗ.

База знаний под AskAI (1–1,5 мин)
Часть знаний для демонстрации вынесена в askai_core_definitions.scs: определения понятий (nrel_definition) и узлы askai_q_* с вариантами вопроса (nrel_main_idtf) и текстом ответа (nrel_answer). Файл авторский, входит в sc-models, попадает в kb.bin через sc-builder и дальше в sc-machine.

Имеет смысл на слайде показать один фрагмент .scs и сказать: «это то, по чему система находит формулировки и ответы».

Контекстные подсказки (1,5–2 мин)
Здесь два разных механизма — их стоит не путать:

Глобальный поиск (SearchField): при вводе строка уходит в searchLinkContentsByContentSubstrings — это живой поиск по содержимому sc-ссылок в уже загруженной памяти; подсказки — не статический список.
Подсказки по синтаксису SCn (в ветке react-sc-web — в Scn.tsx): при наведении на фрагмент текста показывается подсказка по токенам и идентификаторам — для обучения чтению SCn.
Если в вашей сборке только ostis-metasystem, акцент сделайте на поиске; если показываете react-sc-web — добавьте SCn-подсказки.

Связка с платформой (30–40 сек)
sc-machine держит SC-память (kb.bin), sc-server отдаёт WebSocket. sc-web — HTTP и прокси к API. Клиент не знает «имя файла БЗ» — он работает с уже запущенной конфигурацией. Расширение базы — новые .scs в сборке, пересборка и перезапуск.

Итог и демонстрация (1–1,5 мин)
Итог по моей части: AskAI связал естественно-языковой ввод с семантической базой через /api/kb/search/ и прямой резолв в графе; подсказки усиливают поиск и (где реализовано) чтение SCn.

На демо (порядок):

Вопрос из подсказки и свой вопрос по теме из askai_core_definitions.
Поиск по подстроке — показать выпадающий список из памяти.
При наличии — наведение в SCn на токен => или nrel_main_idtf.
Заключение: «Интерфейс не заменяет ядро OSTIS, а даёт удобный слой поверх той же базы знаний и тех же сервисов.»
