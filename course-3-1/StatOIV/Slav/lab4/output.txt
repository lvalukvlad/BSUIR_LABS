4. Оценка качества кластеризации
4.1. Используемые метрики оценки качества:
Внутренние метрики:
 1. Silhouette Score (коэффициент силуэта)
 - Оценивает, насколько объект похож на свой кластер vs соседние кластеры
 - Формула: s = (b - a) / max(a, b)
 где a — среднее расстояние до точек своего кластера
 b — среднее расстояние до точек ближайшего соседнего кластера
 - Диапазон: [-1, 1]
 > 0.7 — отличное разделение кластеров
 > 0.5 — хорошее разделение
 > 0.25 — приемлемое разделение
 < 0.25 — плохое разделение, возможно перекрытие кластеров
 - Чем выше → тем лучше

 2. Davies–Bouldin Index (индекс Дэвиса–Боулдина)
 - Оценивает отношение внутрикластерного расстояния к межкластерному
 - Формула: DB = (1/k) * Σ max((σᵢ + σⱼ) / d(cᵢ, cⱼ))
 где σᵢ — средний радиус кластера i
 d(cᵢ, cⱼ) — расстояние между центроидами кластеров i и j
 - Диапазон: [0, +∞]
 < 1.0 — хорошее разделение
 ≈ 1.0 — удовлетворительное
 > 2.0 — плохое разделение
 - Чем ниже → тем лучше

 3. Calinski–Harabasz Index (индекс Калински–Харабаша)
 - Оценивает отношение межкластерной дисперсии к внутрикластерной
 - Также называется Variance Ratio Criterion
 - Формула: CH = (SSB / (k-1)) / (SSW / (n-k))
 где SSB — межкластерная сумма квадратов
 SSW — внутрикластерная сумма квадратов
 k — число кластеров, n — число объектов
 - Диапазон: [0, +∞]
 Высокое значение — компактные и хорошо разделённые кластеры
 - Чем выше → тем лучше

Внешние метрики (с использованием истинных меток):

 4. Adjusted Rand Index (ARI)
 - Оценивает согласованность кластеризации с истинными метками
 - Диапазон: [-1, 1], где 1 = идеальное совпадение, 0 = случайное

 5. Normalized Mutual Information (NMI)
 - Оценивает информационную общность между кластерами и истинными метками
 - Диапазон: [0, 1], где 1 = идеальное совпадение
