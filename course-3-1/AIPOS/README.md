# AIPOS

Архитектура и программное обеспечение сетей (3 курс, 1 семестр).

| Папка | Содержание |
|-------|------------|
| [lab1](lab1/) | Packet Tracer: сеть, IOS, начальная настройка коммутатора. Отчёт. |
| [lab2](lab2/) | MAC/IP, ARP, IPv6, subnetting. Отчёт и задание по разбиению сетей. |
| [lab3](lab3/) | Статические маршруты, RIP, OSPF. Отчёт. |
| [lab4](lab4/) | VLAN, router-on-a-stick, DNS/DHCP. Отчёт. |
| [lab5](lab5/) | Прокси-сервер на Python (`ProxyServer.py`), отчёт PDF. |

В lab1–lab4 — выполненные `.pka` и отчёты `.docx`. В lab5 — прокси на Python и отчёт.
